# MenaAI Android App

This is a simple Android WebView application for MenaAI.

Website opened automatically:
https://ai.menahost.net/

## Build
Open this folder in Android Studio and choose **Build > Generate App Bundle(s) / APK(s) > Generate APK(s)**.

The supplied MenaAI logo is already configured as the app icon.

Package name:
`net.menahost.menaai`
